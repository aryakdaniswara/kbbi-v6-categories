## English

### Project Description
This repository contains over 420 specialized word lists extracted from the official Kamus Besar Bahasa Indonesia (KBBI) Edisi VI (v6.1.0). These lists are categorized based on official registry markers, covering grammatical, etymological, technical, and social dimensions of the Indonesian language.

### Organization and Methodology
All word lists are generated using a calibrated 1-based absolute indexing system to ensure 100% synchronization with the official KBBI binary assets. This project is intended for research, natural language processing (NLP), and academic study.

## Bahasa Indonesia

### Deskripsi Proyek
Repositori ini berisi lebih dari 420 daftar kata khusus yang diekstrak dari Kamus Besar Bahasa Indonesia (KBBI) Edisi VI (v6.1.0) resmi. Daftar ini dikategorikan berdasarkan penanda registri resmi, mencakup dimensi gramatikal, etimologis, teknis, dan sosial bahasa Indonesia.

### Metodologi
Semua daftar kata dihasilkan menggunakan sistem pengindeksan absolut berbasis 1 yang telah dikalibrasi untuk menjamin sinkronisasi 100% dengan aset biner resmi KBBI. Proyek ini ditujukan untuk penelitian, pemrosesan bahasa alami (NLP), dan studi akademik.
