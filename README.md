## English

### 📑 Project Description
This folder contains over **400 specialized word lists** derived from the official KBBI Edisi VI (v6.1.0). These lists are categorized based on official metadata, providing a granular look at the Indonesian language across scientific, social, and structural dimensions.

### 📂 Classification Groups
- **[01_kelas_kata](01_kelas_kata/)**: Grammatical parts of speech (Nouns, Verbs, etc.).
- **[02_bahasa_asal](02_bahasa_asal/)**: Etymological origins and loanwords (100+ languages).
- **[03_bidang_ilmu](03_bidang_ilmu/)**: Technical vocabulary from specialized fields (Medicine, Law, etc.).
- **[04_ragam_bahasa](04_ragam_bahasa/)**: Social usage registers (Colloquial, Archaic, Vulgar).
- **[05_jenis_entri](05_jenis_entri/)**: Structural types (Root words, Acronyms, Idioms).

### ⚙ Extraction Methodology
All lists are generated using a **Calibrated 1-Based Absolute Indexing** system. This ensures 100% synchronization with the official KBBI database markers, correcting common off-by-one errors found in many raw extractions.

## Bahasa Indonesia

### 📑 Deskripsi Proyek
Folder ini berisi lebih dari **400 daftar kata khusus** yang berasal dari KBBI Edisi VI (v6.1.0) resmi. Daftar ini dikategorikan berdasarkan metadata resmi, menyediakan panduan mendalam tentang bahasa Indonesia di berbagai dimensi ilmiah, sosial, dan struktural.

### 📂 Kelompok Klasifikasi
- **01_kelas_kata**: Kelas kata gramatikal (Nomina, Verba, dll).
- **02_bahasa_asal**: Asal usul etimologis dan kata serapan (100+ bahasa).
- **03_bidang_ilmu**: Kosakata teknis dari bidang khusus (Kedokteran, Hukum, dll).
- **04_ragam_bahasa**: Ragam penggunaan sosial (Cakapan, Arkais, Vulgar).
- **05_jenis_entri**: Jenis struktural (Kata Dasar, Akronim, Idiom).
