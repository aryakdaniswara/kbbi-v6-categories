## English

### Project Overview
This repository provides a comprehensive extraction of the Kamus Besar Bahasa Indonesia (KBBI) Edisi VI (v6.1.0), organized into over 400 specialized word lists. Each list is derived from official binary index files, precisely mapped using calibrated 1-based indexing for 100% data integrity.

## Bahasa Indonesia

### Ikhtisar Proyek
Repositori ini menyediakan ekstraksi komprehensif dari Kamus Besar Bahasa Indonesia (KBBI) Edisi VI (v6.1.0), yang diatur ke dalam lebih dari 400 daftar kata khusus. Setiap daftar berasal dari berkas indeks biner resmi, dipetakan secara akurat menggunakan pengindeksan berbasis 1 yang telah dikalibrasi untuk integritas data 100%.
